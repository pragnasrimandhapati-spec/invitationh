# Mandhapati's House Warming Ceremony

A responsive invitation site for June 21, 2027 in Vatluru. Guests enter their name, rate the new home, and can leave a note. Their visit and submitted response use `sessionStorage` and last for the current browser tab session.

## Open the invitation

Open `index.html` in a modern browser. Bootstrap and the optional Google font files are loaded from their public CDNs; the house illustration is included locally as `home.svg`.

## Included

- `index.html` — invitation, event details, guest entry, rating poll and thank-you state
- `style.css` — responsive colors, layout, petals and interaction styles
- `script.js` — petal animation and session-only guest flow
- `home.svg` — original illustration of a traditional Indian home

No build step or server is required.
